## About This Portfolio

This portfolio is the final project for my Computer Science capstone. It brings together work from across the program and shows how I can take an existing application, review it critically, and improve it through planned enhancements.

The portfolio is organized around three computer science categories: software design and engineering, algorithms and data structures, and databases. Each category focuses on a different part of the same application. This approach shows how one project can be improved from multiple technical perspectives instead of treating each area as a separate, unrelated assignment.

The main artifact in this portfolio is the AAC Rescue application. The original version was a Python Dash dashboard connected to MongoDB animal shelter data. For the capstone, I am enhancing that same artifact into a more complete full-stack application with a stronger structure, better data management, and a more practical user workflow.

The purpose of the portfolio is not just to show finished code. It is also meant to show my process: identifying limitations in the original artifact, planning improvements, making technical decisions, and explaining how those decisions connect to computer science concepts. Each enhancement includes both the updated work and a reflection on what changed, why it changed, and what I learned from the process.
