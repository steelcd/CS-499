## Professional Self-Assessment

I have spent most of my career working directly in manufacturing, beginning in quality and industrial engineering roles before moving into production management and, most recently, operations technology. Throughout those roles, I have used technology to solve operational problems, including databases and front-end tools for manufacturing data collection, quality tracking, MES improvements, and Poka-yoke systems for made-to-order production. More recently, my work has included tools such as Python, Power BI, dbt, Bitbucket, Docker, and cloud-connected manufacturing systems. These experiences helped me realize that the software and systems side of manufacturing is where my strongest interest is, which is why I pursued a Bachelor of Science in Computer Science.

The Computer Science program helped me build a stronger technical foundation for work I was already doing professionally. Software Development Lifecycle helped me better understand agile practices, user stories, user personas, and functional and non-functional requirements. Data Structures and Algorithms gave me more insight into how program logic scales and how design choices affect performance and complexity. Full Stack Development was especially valuable because it tied together front-end development, back-end APIs, databases, and application structure into a working application. These courses helped me better understand how to design systems that are useful, maintainable, and connected to user needs.

This program has also improved how I communicate with different groups involved in a project. In manufacturing, I often need input from operators, supervisors, engineers, managers, and IT teams. Each group may see the problem differently or have different requirements, so it is not enough to explain how a system works. I need to explain how the solution provides value. For example, a solution might improve visibility, reduce manual work, support decision-making, or improve reliability. Most importantly, feedback from these groups helps shape the final solution.

The artifact in this ePortfolio is based on a CS-340 Client/Server Development project for an animal shelter dashboard that used MongoDB, Python, and Dash to help identify animals that could be candidates for rescue training. I enhanced this artifact in three areas: software engineering and design, algorithms and data structures, and databases. In the software engineering enhancement, I moved the project to a full-stack MEVN application by adding a Node/Express API, front-end CRUD functionality, Docker Compose, and a more maintainable project structure. In the algorithms and data structures enhancement, I changed the original hardcoded rescue filters into a profile-driven ranking approach that uses eligibility rules and weighted scoring rules to rank candidate animals. In the database enhancement, I added MongoDB-backed authentication and authorization using user records, password hashing, roles, and shelter claims.

The enhancements changed the original dashboard from a class project that displayed MongoDB data into a more complete application. The project now includes a full-stack structure, API-based logic, user authentication, role-based access, and a scoring method for ranking rescue candidates. This also reflects the type of work I want to continue doing professionally: building software and data systems that solve practical problems in manufacturing operations.

Overall, completing the Computer Science program and developing this ePortfolio helped me better define my professional direction. I entered the program with manufacturing experience and practical exposure to technology, but the coursework helped strengthen my computer science foundation. This portfolio shows my ability to build and improve software, work with databases, think through algorithmic design choices, and consider security as part of the overall system.
